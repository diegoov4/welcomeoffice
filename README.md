# WelcomeOffice — web

Web de WelcomeOffice: equipamiento integral para oficinas, espacios públicos y
hospitales (obra seca, suelos, techos, mamparas y mobiliario interior).

- `assets/img/logo/` — logo, icono y favicons (ver su README).
- Archivos pesados (fotos de producto, fichas técnicas, certificados de
  sostenibilidad) → bucket de Cloudflare R2 `welcomeoffice-media`.
