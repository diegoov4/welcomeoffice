# Logo de WelcomeOffice

Lema: **"Soluciones sostenibles para espacios que inspiran"**

| Archivo | Uso |
|---|---|
| `welcomeoffice-logo.png` / `.jpg` | Logo completo (símbolo + nombre + lema). Cabecera, pie, documentos. |
| `welcomeoffice-icono.png` | Solo el símbolo circular. Redes sociales, avatar, espacios cuadrados. |
| `favicon.ico`, `favicon-32.png` | Icono de pestaña del navegador. |
| `apple-touch-icon.png` | Icono al guardar la web en el móvil (180×180). |

El original mide 476×556 px y tiene fondo blanco (no transparente). Para
pantallas grandes o fondos oscuros conviene pedir el logo en vectorial (SVG) o PNG
transparente a mayor resolución.

## Colores de marca (aproximados, sacados del logo)

| Naranja | `#D07808` | Degradado del arco, acentos |
| Negro azulado | `#0B121A` | "Welcome", textos |
| Blanco | `#FFFFFF` | Fondos |
